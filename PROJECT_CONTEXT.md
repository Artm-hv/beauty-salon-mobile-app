## 1. Загальний опис проекту

Мобільний додаток для керування салоном краси («Svoya Nail Studio») — мобільний аналог / репліка системи **EasyWeek**.
Додаток розроблено на стекі:
* **React Native (Expo SDK 57)**
* **TypeScript** (строга типізація, 0 помилок `tsc --noEmit`)
* **React Native Paper** (компоненти UI та Material Icons)
* **Expo Router** (файлова маршрутизація: вкладки `app/(tabs)`)
* **Сенсори:** `expo-sensors` (акселерометр для перемикання дат розкладу жестами), `expo-camera` (фотофіксація результатів процедур).

Дизайн виконано в преміальному темному стилі (EasyWeek Dark Edition: фон `#000000`, картки `#1C1C20`, акценти `#4CAF50`, `#38BDF8`, `#8B5CF6`).

## 5. Деталі реалізованих екранів та фіч

### 🗓 1. Календар (`app/(tabs)/calendar.tsx`) — Ігор
* Горизонтальна сітка з колонками майстрів: Гіжовська Вероніка, Юлія Півень, Таня Майстер.
* Вертикальна шкала часу від `10:00` до `21:00`.
* **Червона динамічна риска** поточного часу з червоною крапкою зліва, яка автоматично оновлюється щохвилини.
* **Навігація по датах:**
  1. Нахил або струшування телефону вліво-вправо (акселерометр через `useAccelerometer.ts`).
  2. Свайп пальцем по верхній шапці або нижній панелі дат (`PanResponder`).
  3. Стрілочки `‹` та `›` біля заголовка дати.
  4. Натискання на дні в нижній смузі (`Сб, 10`, `Нд, 11`, `Пн, 12`...).
* Зворотний зв'язок: спливаюча плашка `Snackbar` з повідомленням про зміну дати.

### ➕ 2. Нове бронювання (`app/(tabs)/new-booking.tsx`) — Артем Г
* Верхній бар: кнопка `←` та `↻ Повторювати`.
* Картка дати/часу з плаваючим бейджем календаря/годинника `📅`, текстом `Сб, 10 жовт 2026 р. 20:35 ⌵` та синьою кнопкою `+ Новий запис ▾`.
* Картка **Послуги** з пунктирною рамкою `+ Додати послугу` та модальним вибором послуг.
* Картка **Клієнт** з зеленим посиланням `СТВОРИТИ НОВОГО` та вибором клієнта з іконкою інкогніто.
* Картка **Примітки**: лаконічне поле для внутрішніх коментарів.
* Картка **Підсумок**: сума за бронювання.
* Поле **Коментар**, селектор **Джерело замовлення** (`По телефону ▾`), плашка **Створено: Клієнт** та горизонтальна палітра з 11 кольорових кружечків з кнопкою `[Авто]`.
* Нижня фіксована панель дій: зелена кнопка `💾 Зберегти` та біла кнопка `Оплата ›`.

### 👥 3. База клієнтів CRM (`app/(tabs)/clients.tsx` та `ClientCard.tsx`) — Артем Г
* Верхній бар з кнопкою `...`.
* Заголовок `Клієнти`.
* Сегментований перемикач вкладок: `Всі`, `Нові`, `Неактивні`, `Без запису`.
* Рядок пошуку з іконкою лупи `🔍` та кнопка фільтрів `☰`.
* Інформаційна плашка: лічильник `15 клієнтів показано з 2502` та кнопка `Множинний вибір`.
* Картки клієнтів:
  * Фіолетова кругла аватарка з літерою `O`, ім'я (наприклад `ольга`), код `CN-1013`, стрілка `›` або зелена кнопка `+ Додати` (для `Оля CN-2100`).
  * Рядки: `Теги` (`Додати теги`), `Телефон` (зелена галочка `✓` + `+380 67 278 8818 ▾`), `Візитів` (32), `Середній чек` (726,88 ₴), `Оплачено` (23 260,00 ₴).

### 🧾 4. Каса / Замовлення (`app/(tabs)/cashier.tsx` та `OrderCard.tsx`) — Артем Г
* Кнопка повернення `←` та заголовок `Замовлення`.
* Сегментовані вкладки: `Всі`, `Не сплачено`, `Завершено`, `Скасовано`.
* Фільтр періоду: `10 вер 2026 р. - 11 жовт 2026 р. ▾`.
* Фільтр виконавця: `Виконавець ▾`.
* Поле швидкого пошуку замовлення.
* Картка чека:
  * Номер чека (напр. `Замовлення №8142`) та стрілочка `›`.
  * Зелена плашка зі статусом `✓ Завершено`.
  * Дані: `Створено` (10 жовт 2026 р. 19:35), `Клієнт` (фіолетова цятка + `ольга`), `Касир` (салатова цятка + `Настя Кобзар`), `Кількість` (1), `Всього` (700,00 ₴).
* Плаваюча зелена кнопка внизу справа: `🛒 Нове замовлення`.

## 6. Як запустити та протестувати

1. **Клонування / підтягування змін:**
   ```bash
   git pull origin main
   ```
2. **Встановлення залежностей (якщо новий ПК):**
   ```bash
   npm install --legacy-peer-deps
   ```
3. **Перевірка типів TypeScript:**
   ```bash
   npx tsc --noEmit
   ```
4. **Запуск проекту для телефону:**
   ```bash
   npx expo start --tunnel
   ```
   * Сканувати QR-код через додаток **Expo Go** на iPhone або Android.
   * Прапорець `--tunnel` забезпечує пряме підключення навіть якщо комп'ютер і телефон у різних Wi-Fi мережах.
