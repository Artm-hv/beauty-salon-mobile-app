# 📱 Svoya Nail Studio – Мобільний додаток управління салоном краси

> Університетський проєкт з предмету **"Aplikacje mobilne" (Semestr 5)**  
> Розроблено для салону краси на базі React Native (Expo) та FastAPI.

---

## 👥 Команда та розподіл обов'язків

1. **Ігор (Розробник 1):**
   - Авторизаційний потік (Вхід, Реєстрація)
   - Екран очікування схвалення ролі (RBAC gatekeeper)
   - Екран розкладу майстрів (Календар із сіткою часу)
   - Сенсор акселерометра (перемикання дати струшуванням)

2. **Артем Г (Розробник 2):**
   - Каса та замовлення
   - Оформлення нового запису
   - CRM клієнтів з LTV
   - Сенсор камери (фотофіксація результату послуги)

3. **Артем Л (Розробник 3):**
   - Меню налаштувань
   - Управління персоналом та надання ролей
   - Статистика місяця та графіки джерел бронювань
   - Зарплата майстра та двомовність (PL/UA)

---

## 🛠 Технічний стек

- **Клієнт:** React Native (Expo Router, TypeScript)
- **UI Framework:** React Native Paper (Material Design 3)
- **Сенсори:** `expo-sensors` (Акселерометр), `expo-image-picker` (Камера)
- **Бекенд:** FastAPI (Python), PostgreSQL, JWT Auth
