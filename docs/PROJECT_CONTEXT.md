# Svoya Nail Studio — контекст проєкту

Робочий каталог Expo — `application/`. Шляхи нижче наведені від нього. У [польському README](../README.md) описано запуск, внесок кожного учасника й три файли для захисту. Кореневий `Uruchom_Serwer.bat` запускає API та пропонує LAN, тунель або браузер.

## Архітектура

Клієнт використовує Expo SDK 58, React Native 0.88, TypeScript і React Native Paper. Екрани містяться в `app/`, вкладки — в `app/(tabs)/`, типи даних салону — в `constants/salonTypes.ts`. Клієнт у `services/api.ts` знаходить API та додає токен сесії до запитів. Metro пересилає запити з префіксом `/api/` на Python-сервер на порту 8000. Можливе й пряме підключення до API.

Сервер у `backend/server.py` використовує `http.server`. У `data/database.json` зберігаються користувачі, майстри, клієнти, візити й чеки. Сервер записує зміни через тимчасовий файл із заміною основного.

## Авторизація та ролі

Паролі зберігаються як хеші PBKDF2 із сіллю. Після входу сервер видає випадковий токен. Сесія діє до 24 годин і завершується після перезапуску сервера. Застосунок перевіряє стан сесії під час роботи й при поверненні на передній план.

- **PENDING.** Новий працівник очікує на призначення ролі. Сервер перевіряє унікальність пошти.
- **MASTER.** Сервер знаходить майстра за зв’язком із `userId` та повертає його записи. Майстер може додавати фото, завершувати візити й переглядати комісію.
- **ADMIN.** Адміністратор керує розкладом, персоналом, касою та клієнтами й переглядає статистику. Відкликання чинної ролі або звільнення анулює сесії працівника. Записи неактивного майстра залишаються доступними для перепризначення.

## Від бронювання до оплати

Під час бронювання сервер перевіряє доступність майстра та перетин повного інтервалу візиту. Разом із записом створюється неоплачений чек зі списком послуг і загальною сумою. Перенесення візиту також проходить перевірку зайнятості. Дні календаря можна перемикати нахилом телефона завдяки `hooks/useAccelerometer.ts`. У деталях візиту `hooks/useCamera.ts` отримує фото з камери або галереї. Нові фото зберігаються як дані зображення у спільному записі.

Візит має статус `CONFIRMED`, `COMPLETED` або `CANCELLED`. Чек має власний статус `UNPAID`, `COMPLETED` або `CANCELLED`. Оплата й скасування оплати змінюють ознаку `hasPayment` пов’язаного візиту та його відображення в календарі.

## CRM, зарплата й статистика

- `services/clientMetrics.ts` пов’язує операції з карткою клієнта за ідентифікатором. Для старих даних використовує однозначний збіг телефону або імені. Враховує історичні показники імпортованих карток та оплачені записи без пов’язаного чека.
- `app/salary.tsx` відбирає завершені або оплачені візити поточного майстра. Комісія становить 75% ціни. Баланс враховує оплачену частину.
- `app/statistics.tsx` групує записи за місяцем, днем і джерелом бронювання. Чинний лічильник завершених у звіті та лічильник візитів у CRM враховують і оплачені візити, зокрема передоплату.
- Переклади PL/UA містяться в `constants/i18n.ts`. За мову та тему відповідає `context/AppSettingsContext.tsx`. Початкові налаштування — польська мова та темна тема.

## Перевірка

Команди перевірки TypeScript, експорту Expo та запуску тестів наведені в README. П’ять HTTP-тестів у `backend/test_server.py` працюють із тимчасовою базою. Перед захистом на телефоні варто пройти вхід, перемкнути день нахилом і зберегти фото до візиту.
